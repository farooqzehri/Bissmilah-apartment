# Project Instructions

## Coding and Architecture Principles
- **Clean and Modular**: Always write clean, modular code with descriptive, human-readable comments.
- **No Monoliths**: Do not combine all component logic or application screens into a single massive file (like a massive `App.tsx`). Break components and helper logic down into smaller, highly structured functions, custom hooks, or separate modular files within `/src/components/*` or `/src/utils/*`.
