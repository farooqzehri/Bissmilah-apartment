# Bismillah Real Estate & Apartments
## MongoDB Atlas & Cloudinary Integration Guide

This guide provides step-by-step instructions to configure **MongoDB Atlas** (cloud database) and **Cloudinary** (cloud image and asset storage) for production-grade dynamic persistence and high-speed image CDN delivery.

---

## 1. MongoDB Atlas Setup Guide

MongoDB Atlas provides a free-tier (M0 Sandbox) hosted database that requires no server maintenance.

### Step 1: Create an Account & Project
1. Visit [mongodb.com/cloud/atlas/register](https://www.mongodb.com/cloud/atlas/register) and create a free account.
2. Sign in to the **MongoDB Atlas Console**.
3. Create an Organization and a New Project (e.g., `Bismillah-Real-Estate`).

### Step 2: Deploy a Free M0 Cluster
1. In the console, click **Create** or **Build a Database**.
2. Select the **M0 Free** (Shared) tier:
   - Cloud Provider: **AWS**, **Google Cloud**, or **Azure**.
   - Region: Select a region close to your primary audience (e.g., `ap-south-1` Mumbai or `me-south-1` Bahrain).
3. Name your cluster (e.g., `Cluster0` or `BismillahCluster`) and click **Create Deployment**.

### Step 3: Configure Database User (Credentials)
1. In the left navigation bar under **Security**, click **Database Access**.
2. Click **Add New Database User**.
3. Authentication Method: **Password**.
4. Set a Username (e.g., `bismillah_admin`).
5. Set an Autogenerated or secure Password (e.g., `SecurePass786!`). **Save this password securely**.
6. Set Database User Privileges to **Read and write to any database** (`readWriteAnyDatabase`).
7. Click **Add User**.

### Step 4: Configure Network Access (IP Whitelist)
1. In the left navigation bar under **Security**, click **Network Access**.
2. Click **Add IP Address**.
3. To allow connections from any cloud deployment or local development environment, click **Allow Access from Anywhere** (this enters `0.0.0.0/0`).
4. (Optional) Provide a comment such as `Allow Cloud Applet Deployment`.
5. Click **Confirm**. The status will change from *Pending* to *Active* within 10-30 seconds.

### Step 5: Copy the Connection String (SRV URI)
1. In the left navigation bar under **Deployment**, click **Database**.
2. On your cluster card, click **Connect**.
3. Choose **Drivers** (Node.js).
4. Copy the connection string. It looks like:
   ```text
   mongodb+srv://<username>:<password>@cluster0.abcde.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0
   ```
5. Replace `<username>` with your database username and `<password>` with the password created in Step 3.
6. Specify the database name before the `?` query parameter:
   ```text
   mongodb+srv://bismillah_admin:SecurePass786!@cluster0.abcde.mongodb.net/bismillah_apartments?retryWrites=true&w=majority
   ```
7. Set this value in your `.env` file as:
   ```env
   MONGODB_URI=mongodb+srv://bismillah_admin:SecurePass786!@cluster0.abcde.mongodb.net/bismillah_apartments?retryWrites=true&w=majority
   ```

## 2. Cloudinary Image Storage Setup Guide

Cloudinary hosts, optimizes, and transforms images with global CDN delivery.

### Step 1: Create a Cloudinary Account
1. Visit [cloudinary.com/users/register_free](https://cloudinary.com/users/register_free) and sign up for a free plan.
2. Sign in to your **Cloudinary Dashboard**.

### Step 2: Obtain API Credentials
1. From the Cloudinary Console Dashboard (Summary section), locate your **Product Environment Credentials**:
   - **Cloud Name** (e.g., `dw4k9x8la`)
   - **API Key** (e.g., `482915839217482`)
   - **API Secret** (e.g., `abcde_FgHiJkLmNoPqRsTuVwXyZ`)
2. Click the copy icon next to each credential.

### Step 3: Configure Environment Variables
Add these values to your `.env` file:
```env
CLOUDINARY_CLOUD_NAME=dw4k9x8la
CLOUDINARY_API_KEY=482915839217482
CLOUDINARY_API_SECRET=abcde_FgHiJkLmNoPqRsTuVwXyZ
```

*(Note: Never expose `CLOUDINARY_API_SECRET` to the frontend or git repositories. All uploads and deletions are securely proxied through the Express server at `/api/media/upload` and `/api/media/:id`.)*

## 3. Environment Variables Summary (.env)

Create a `.env` file in the root directory (based on `.env.example`):

```env
# Server Port
PORT=3000

# MongoDB Atlas Database URI
MONGODB_URI=mongodb+srv://bismillah_admin:YourPassword@cluster0.abcde.mongodb.net/bismillah_apartments?retryWrites=true&w=majority

# Cloudinary Storage Credentials
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret

# JWT Authentication Secret
JWT_SECRET=super_secret_jwt_key_bismillah_786_california_luxury
```

## 4. Automatic Seeding & Resilience Architecture

The application is built with a dual-layer architecture:
1. **With MongoDB Atlas**: When `MONGODB_URI` is supplied, Mongoose connects to your cluster. If the collections are empty, the backend automatically seeds initial properties, settings, customer inquiries, and the default admin profile (`username: admin`, staff PIN: `786`).
2. **With Cloudinary**: Uploaded property images, logos, and favicons are delivered via Cloudinary's secure CDN. The database stores the high-res CDN `url` and `publicId`. Deleting a property or replacing an image automatically cleans up the remote asset on Cloudinary.
3. **Resilience Fallback**: If either credential is not yet configured, the system gracefully operates on local disk storage and mock memory to prevent crashes or downtime during setup.

## 5. Local Running & Deployment Commands

### Running Locally in Development Mode
```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Start the Express backend + Vite dev server concurrently
npm run dev
```
The application will be accessible at `http://localhost:3000`.

### Building for Production
```bash
# Compile TypeScript and bundle frontend with Vite
npm run build
```

### Running in Production
```bash
# Run server.ts with Node / tsx
npm start
```

## 6. Verifying Integration

1. **Admin Portal**: Go to the Admin Dashboard (default Staff PIN is `786`).
2. **Media Manager**: Open the **Media Manager** tab. A live status card at the top will verify:
   - `MongoDB Atlas: Connected (Mongoose)`
   - `Cloudinary CDN: Active (Folder: bismillah_apartments)`
3. **Upload Test**:
   - Upload any image in **Media Manager** or while creating a **Property**.
   - The image URL will begin with `https://res.cloudinary.com/...` and the unique `public_id` will be saved to your MongoDB Atlas document.
